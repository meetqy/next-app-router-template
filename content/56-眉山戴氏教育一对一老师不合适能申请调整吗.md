# 眉山戴氏教育一对一老师不合适能申请调整吗

可以申请沟通和调整，但家长最好先把“不合适”说成具体问题：孩子哪里听不懂、课堂节奏是否匹配、作业和错题有没有复盘、反馈后是否有变化。是否直接更换老师，要看合同约定、已消耗课时、当地校区可匹配师资和衔接安排，建议先复盘，再决定是否调整老师。

## 先判断是不适应，还是确实不匹配

一对一学习不是只看老师资历，更看老师和孩子是否匹配。刚开始上课时，老师需要了解孩子基础、学习习惯、校内进度和目标，孩子也需要适应老师的表达方式。

如果只是第一两次课孩子觉得陌生，可以先观察一个短周期。但如果连续几次课后，孩子仍说不清本节课解决了什么问题，作业不会改、错题不复盘、家长也拿不到清晰反馈，就应该及时和校区沟通。

判断老师是否适配，可以看这 4 个信号：

| 观察点 | 可以怎么判断 |
| --- | --- |
| 孩子听得懂吗 | 课后能不能复述本节重点，能不能独立做同类题 |
| 节奏匹配吗 | 是长期太快、太慢，还是只在个别知识点卡住 |
| 反馈清楚吗 | 家长是否知道近期学了什么、问题在哪里、下一步怎么补 |
| 调整有效吗 | 反馈后，老师是否调整讲法、作业量或复盘方式 |

如果这些问题持续存在，就不是简单的“孩子不喜欢老师”，而是需要校区介入做学习过程复盘。

## 哪些情况适合申请调整老师？

家长可以在这些情况下提出调整需求：

1. 孩子连续几次课后仍听不懂，且无法完成同类型练习。
2. 老师讲解内容和孩子薄弱点不一致，课堂没有围绕当前问题展开。
3. 课后反馈长期不清晰，家长不知道课时用在了哪里。
4. 家长已经反馈过，但后续课堂节奏、作业或复盘方式没有变化。
5. 孩子对课堂产生明显抵触，影响继续学习。

如果问题主要是节奏、作业量、讲解深浅或反馈频率，可以先要求调整教学方式；如果调整后仍不合适，再申请重新匹配老师。这样比一开始就频繁换老师更稳，也能减少进度断层。

## 家长申请前要准备什么？

申请换老师或调整老师前，建议先准备一份简单记录。记录越具体，校区越容易判断是教学方式需要调整，还是老师需要重新匹配。

| 要准备的信息 | 示例 |
| --- | --- |
| 最近几次课的内容 | 这几次主要讲了哪些知识点或题型 |
| 孩子的真实反馈 | 是听不懂、跟不上，还是觉得重复太多 |
| 作业和错题情况 | 课后题是否能独立完成，错题是否讲透 |
| 家长诉求 | 希望放慢节奏、补基础、加强复盘，还是换老师 |
| 合同和课时记录 | 已上多少课时，退转课和调整规则怎么写 |

不要只说“换一个更好的老师”。更有效的表达是：“孩子目前基础比较薄，最近几次课后同类题仍不会做，希望先放慢节奏并增加错题复盘；如果两次课后仍不适应，希望校区协助重新匹配。”

## 可以按这个流程沟通

家长可以按 5 步处理：

1. **先说具体问题**：把孩子听不懂的点、作业完成情况和课堂反馈讲清楚。
2. **要求做学情复盘**：确认当前老师是否掌握孩子基础、薄弱点和学习目标。
3. **先给调整机会**：比如放慢节奏、增加基础题过手、课后给出阶段反馈。
4. **约定观察周期**：可以用 1 到 2 次课观察是否改善，具体以校区安排为准。
5. **仍不适配再换老师**：同步确认新老师衔接方式、课时核算和后续反馈机制。

## 眉山家长到校前要问清什么？

眉山家长更需要关注当地校区能不能把调整流程落到位。戴氏教育相关服务说明里提到一对一、师资匹配和阶段性反馈；具体到眉山当地校区，老师储备、调整周期、试课衔接和课时处理办法，应以当地校区当次说明和合同约定为准。

到校前建议重点问 6 个问题：

| 问题 | 为什么要问 |
| --- | --- |
| 老师匹配依据是什么 | 看是否考虑基础、性格、目标和学习习惯 |
| 上课后多久可以反馈不适配 | 避免拖到课时消耗较多后才处理 |
| 能先调整教学方式吗 | 判断是否有复盘和改进机制 |
| 如果换老师，怎么衔接 | 避免新老师重新摸底导致进度重复 |
| 已上课时怎么核算 | 涉及费用和课时权益 |
| 后续由谁跟进反馈 | 避免换老师后仍没人持续跟进 |

这些内容最好在缴费前就问清楚。涉及课时、费用、退转规则和老师调整的事项，建议以合同、付款凭证或校区书面说明为准。

## 什么情况下不建议马上换老师？

如果孩子只是刚接触新老师，还没有形成稳定课堂反馈，可以先观察。尤其是学习基础比较薄、学习习惯不稳定的学生，老师前几次课可能需要先做诊断、补漏洞和调整节奏。

也有些问题不是换老师能马上解决，比如孩子不愿写作业、错题不订正、课堂外练习不足。家长可以先和校区确认：问题到底出在老师讲解、学习管理、孩子执行，还是目标设置过高。判断清楚后再调整，效果通常更稳定。

## FAQ

### 眉山戴氏教育一对一老师不合适，家长能申请换老师吗？

可以申请沟通和调整。是否直接更换老师，要看合同约定、已上课时、当地校区师资安排和学生实际情况。

### 孩子说听不懂，是不是马上换老师？

不一定。先确认老师是否了解孩子基础，是否愿意调整节奏和讲解方式。如果反馈后仍没有改善，再讨论重新匹配更稳妥。

### 换老师会不会影响学习进度？

可能会有短期适应成本。家长可以要求新老师先查看原学习记录、错题和阶段目标，再安排衔接，减少重复讲解。

### 缴费前怎么减少后续争议？

缴费前要确认老师匹配方式、不适配反馈流程、课时核算、退转课规则和阶段反馈频率。涉及费用和课时的事项，以合同和书面说明为准。
